# Judge demo

Open **https://ethcraft-arkiv.quiet-buddy-9104.chatgpt.site** in an ordinary browser. No account, wallet, Discord or running game is required to inspect these public records.

1. Click **Read live from Arkiv**. Show the returned Rabdi block number and the actual worker stages. The demonstrated task has a four-step Agent stage and a five-step 0G stage, linked by the owner's handoff.
2. On the 0G card, click **Read previous worker's progress**. A fresh entity read shows the paused source stage used by the handoff, with its publisher, revision and expiry.
3. Open **View exact Arkiv record**, then the **Open source** link. Judges can inspect the typed fields or clone the public repository and run `npm ci --ignore-scripts` followed by `npm run query` independently.

Say: “The player keeps their private objective and approval on the game server. Public observed progress is owned and queried on Arkiv. Another worker reads that record, then checks the actual world and its own supplies before continuing.”

Do not call the receipt commitment independent proof of Minecraft behavior, claim owner acceptance from `ready_for_review`, or present the extraction as a project built from scratch. Seven-day records can expire; refresh the demo before presenting. Controlled data fixtures are clearly labelled and hidden by default.

New game actions still require the approved player's Minecraft session and the existing host/inference budgets. The public website exposes only reads, never wallet signing, Discord credentials or game control.
