# Verification requirements

Local Phase1 now uses the user-approved focused MVP gate. The original257 requirement families remain semantically preserved; broader Phase1 and original14 Phase2 qualification families are retained under Phase9. Local Phase2 uses six focused functional cases and makes no distributed task-lease claim. The expanded1041-variant sweep and35 additive regressions are archived reference material, not this local gate.
